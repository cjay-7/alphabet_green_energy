## Full description (max 4000 characters)

Alphabet Green Energy is a field data-collection app built for agents
working on a clean cookstove distribution and monitoring program.

**What agents can do with the app:**

- Register new beneficiaries and primary beneficiaries, capturing
  contact details, address, and government ID verification with photos.
- Record stove handover with GPS-tagged photo evidence.
- Look up an existing beneficiary and log a follow-up revisit —
  confirming the stove is still in use and working properly.
- Conduct household surveys covering fuel usage and household size.
- Work in areas with unreliable connectivity: data and photos are saved
  on the device and automatically synced to the server once a network
  connection is available.

This app is intended for use by trained field agents as part of an
organized program, not for general public use.
